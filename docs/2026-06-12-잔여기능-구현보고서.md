## 2. 구현 내역

### [M1] 출퇴근 지도: 현위치 중앙 + 원 + 펄스 (PPT 슬라이드3)
- 카메라 정책을 '현위치 항상 중앙 고정'으로 변경 (출근지 대칭점 mirror-point fit으로 출근지 원도 화면 내 유지, 줌 클램프)
- 현위치 중심 원 추가 (#2DDAA9, GPS 정확도 기반 15~60m 클램프)
- 하트비트 펄스: 출근지 중심에서 radius_m 경계까지 맥동 (미터 기반 폴리곤 → 줌 반응형)
- 저줌 출근지 마커 컬링(WIP) 해결: CompetitionType.none 전용 라벨 레이어 (실험적 — 실기기 확인 필요)
- 파일: `attendance_app/.../attendance_screen.dart`

### [D11] 승인 대기 화면 폴링 (PPT 슬라이드11)
- 공개 API 2개 신설: `POST /auth/device/status`(상태 조회, 비밀번호 불요), `POST /auth/device/cancel`(비밀번호 재검증 후 PENDING 삭제, REJECTED 보존)
- 대기 화면 5초 폴링 → APPROVED 감지 시 '접속하기' 버튼 활성화, '요청취소'는 서버 row 실제 삭제
- login/register → 대기 화면 진입 시 자격증명 extra 전달 계약 확립
- 파일: `AuthService.kt`, `AuthController.kt`, `DeviceStatusRequest.kt`(신규), `device_waiting_screen.dart`, `login_screen.dart`, `app_router.dart`, `api_constants.dart`

### [D10] 관리자 거절 시 취소 안내 (PPT 슬라이드10)
- REJECTED 기기 로그인 시: 제목 '접속 요청이 취소 되었습니다' / 본문 '인사부서에 문의 하시기 바랍니다.' + '확인' 단일 버튼(비밀번호만 초기화)
- 파일: `login_screen.dart`

### [D3] 신규 가입 시 인사정보 사전 대조 (PPT 슬라이드7·9)
- 가입을 '신규 생성' → '관리자가 사전 등록한 미가입 직원 row에 비밀번호 설정+활성화'로 전환
- `users.password_hash` NULL 허용 (NULL=미가입), 관리자 직원 등록에서 비밀번호 입력 제거
- 신규 `POST /auth/register`: 미등재/불일치 → '입력한 정보가 일치하지 않습니다. 인사부서에 문의하세요' (PPT 문구), 재가입 → '이미 등록된 사원번호입니다'
- 미가입자 로그인 시도 NPE 방어 포함
- 파일: `schema.sql`, `seed.sql`, `User.kt`, `UserService.kt`, `AuthService.kt`, `AuthController.kt`, `RegisterRequest.kt`(신규), `CreateUserRequest.kt`, `employees_page.dart`, `api_service.dart`(web), `register_screen.dart`, `api_constants.dart`

### [D4] 기기 등록 방식 설정: 자동(a)/관리자 승인(b) (PPT 슬라이드7)
- `companies.device_binding_mode` 컬럼(AUTO|APPROVAL, 기본 AUTO) + `verifyDeviceBinding` 분기
- 관리자 설정 API `GET/PUT /admin/settings/device-binding` + 기기 승인 페이지 SegmentedButton 토글
- APPROVAL 모드 가입 직후: 자동 승인요청(PENDING) 생성 후 대기 화면 직행
- 파일: `schema.sql`, `seed.sql`, `DeviceBindingMode.kt`(신규), `Company.kt`, `AuthService.kt`, `DeviceAdminService.kt`, `AdminController.kt`, DTO 2개(신규), `device_requests_page.dart`, `api_service.dart`(web), `register_screen.dart`
